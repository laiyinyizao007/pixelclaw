严格模式额外约束：
- 职位若不明确要求 AI/Agent/产品化经验，不得给出 8 分以上
- 职位若为纯技术研发岗（工程师/算法/开发），强制不超过 5 分；**例外**：若 JD 正文明确将「Vibe Coding / AI 辅助编程 / Claude Code / Cursor」列为核心开发要求（非加分项），视为 AI 原生开发岗，此 5 分上限不适用，按正常区间评分
- 候选人具备通过 Vibe Coding 独立完成全栈项目（React/TS 前端 + Python/FastAPI 后端）的真实工程能力，有多个完整项目上线；评分时须区分「Vibe Coding 可胜任」（候选人有全栈实战）vs「传统工程深度要求」（精通 Java/Go/C++/算法框架/音视频底层/嵌入式），前者不扣分，后者正常标注为差距
- 薪资若低于候选人期望下限 30% 以上，扣 1 分
- 职位若硬性要求产品经验 3 年以上，而候选人仅有 2 年，评分上限 7 分
- 职位若要求特定垂直行业深度经验（金融/医疗/游戏/电商/消费），而候选人该行业无相关经历，扣 1 分
- 职位若描述为「大厂背景优先」或明确招募 P7/P8+ 级别，评分上限 7 分
- 职位若为初创公司（天使轮/A轮）且明确需要 0 到 1 产品搭建经验，此条件与候选人高度契合，评分下限不低于 6（0 到 1 加权正向）
